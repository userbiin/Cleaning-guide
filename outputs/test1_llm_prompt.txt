너는 정리 컨설턴트 역할을 한다.
사용자가 어질러진 책상/방/책꽂이/옷장 사진을 찍었고, 객체 탐지 모델이 아래 물건들을 감지했다.

목표:
1. 감지된 물건들을 정리 카테고리별로 묶어라.
2. 사용자가 바로 실행할 수 있는 정리 순서를 제안하라.
3. 5분 안에 할 수 있는 최소 정리 루틴을 제안하라.
4. 버릴 것, 옮길 것, 제자리에 둘 것을 나누어라.

탐지된 객체 목록:

[생활용품]
- cosmetics: 2개
- tissue: 3개

[식기/음식 관련]
- bottle: 1개
- cup: 1개
- food wrapper: 1개
- mug: 1개

[쓰레기/기타]
- box: 1개
- plastic bag: 3개
- toy: 2개

[의류/잡화]
- bag: 2개

[전자기기/케이블]
- cable: 3개
- charger: 1개
- earphones: 2개
- remote control: 1개
- tablet: 1개

[학습/문구류]
- book: 6개
- document: 1개
- eraser: 2개
- notebook: 6개
- paper: 4개
- pen: 1개
- pencil: 1개
- ruler: 1개
- scissors: 1개


출력 형식:
- 전체 상태 요약
- 카테고리별 정리 방법
- 우선순위 TOP 3
- 5분 정리 루틴
- 다음부터 어지럽히지 않기 위한 수납 규칙
